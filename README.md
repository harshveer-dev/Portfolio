## 📸 Overview

This is the official personal portfolio website of **Harshveer**, a Python Developer & Software Engineer based in **Jaipur, Rajasthan, India**. The portfolio showcases skills, featured projects, education timeline, work experience, and a working contact form — all in a sleek dark-themed design with smooth scroll animations.

---

## ✨ Features

- 🌑 **Dark Theme Design** — Professional dark glassmorphism aesthetic with purple accent colors
- 🎬 **Scroll Animations** — Elements gracefully reveal on scroll using the Intersection Observer API
- ⌨️ **Typing Effect** — Dynamic role typewriter animation in the hero section
- 📱 **Fully Responsive** — Mobile-first layout with hamburger menu for small screens
- 🧭 **Active Nav Highlighting** — Navigation links auto-highlight based on scroll position
- 📊 **Animated Skill Bars** — Progress bars animate into view when scrolled to the Skills section
- 🖥️ **Sticky Header** — Header with blur/shadow effect on scroll
- 📬 **Contact Form** — Functional contact form with validation feedback
- 🔝 **Back-to-Top Button** — Smooth scroll to top from the footer
- 🎨 **Tech Pill Tags** — Visual technology badges in the Skills section
- 🃏 **Project Cards** — Hover-effect cards for each featured project

## ⚙️ Setup & Usage

No build tools, frameworks, or package managers are required. Just open the file in any modern browser.

### ▶️ Option 1 — Direct Open
```
Double-click index.html to open in your default browser
```

### ▶️ Option 2 — Live Server (Recommended for Development)
If you have **VS Code** with the **Live Server** extension:
1. Open the `My portfolio` folder in VS Code
2. Right-click `index.html` → **Open with Live Server**
3. Visit `http://localhost:5500` in your browser

### ▶️ Option 3 — Python HTTP Server
```bash
cd "c:\Users\harshveer\OneDrive\Desktop\My portfolio"
python -m http.server 5500
# Then open: http://localhost:5500
```
